# @vessel-dsp/visual-effects

Reusable Three.js preview effects for VesselDSP generated 3D models.

This package owns shared visual styling helpers used by generated preview
packages, including toon material conversion, toon outlines, material grain
metadata, and lightweight glitch/grain pass descriptors.

It is intentionally focused on Three.js preview rendering and does not import
React, editor code, or audio runtime code.
