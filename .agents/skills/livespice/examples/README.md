# LiveSPICE Example Fixtures

These `.schx` files are bundled with the skill so it can be copied into another
project without depending on this repository's fixtures.

- `passive-lowpass-rc.schx` is copied from upstream
  `dsharlet/LiveSPICE` `Tests/Examples/Passive 1stOrder Lowpass RC.schx`.
- `t-junction.schx` is a compact geometry fixture for wire-body junctions.
- `unknown-component.schx` is a compact diagnostic fixture for unsupported
  `_Type` handling.
