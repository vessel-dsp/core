## 2. The law attempt (reverted, not shipped) — what was tried and measured

Lowering tried: bar as RB1/RB2 conductances split at eta, emitter diode (silicon
IS/n) anode-sense → cathode-tap, emitter-current modulation as a VCCS withdrawing
k·Ie from tap to B1 (sense resistor Rs in the emitter leg), plus a clamp diode across
Rs for saturation. All existing stamps. Test circuit (synthetic part eta=0.63,
Rbb=4.7k; 12 V rail; Rt=47k to emitter; Ct=100 nF emitter→gnd; 100 Ω base returns).

- While running it is quantitatively right: 73 consecutive cycles, emitter sawtooth
  4.2 V (valley, emergent) ↔ 8.0 V (peak; predicted eta·Vbb+Vd ≈ 8.1 V). Measured period
  ≈ 3.2 ms vs the corrected RC law Rt·Ct·ln((Vs−Vv)/(Vs−Vp)) = 3.14 ms (**2 %**); vs the
  ideal Vv→0 formula 4.67 ms (0.69× — the valley explains the gap; tolerance §4).
- Then it dies: every ~70th peak crossing stalls Newton (24k+ exhausted iterations,
  1024 cap), the hold freezes the state at the peak, and the run never recovers.
  k ∈ {1.5, 2, 2.5, 4, 5} and Rs ∈ {100, 300} only move the failure mode
  (immediate park, blow-up to ±1e306, or delayed stall) — never remove it.
- ngspice agrees: the same topology in a `.cir` deck timestep-collapses exactly at the
  firing instant (t = 5.18013 ms ≈ predicted charge time 5.3 ms) for k = 3 and k = 1.5.
- Static control (VCCS factor 0, same stamps otherwise): converges cleanly (peak
  iterations 1, 0 non-converged), parks at the peak clamp 8.19 V, never oscillates —
  proving the oscillation comes from the modulation loop and the stall from its
  Newton crossing, not from the bar/diode/sense or the harness.

Root cause: the firing point is a Jacobian singularity (det = 0 where loop gain
crosses 1, at emitter current Ip = Vt/(Rpar·(k−1))). Newton must cross it twice per
cycle; the band is microamp-narrow, the hold mechanism poisons the run on the first
miss, and the miss rate (~1.4 %/crossing observed) guarantees death within seconds.
A no-singularity regime (k ≤ 1+Rs/Rpar, det > 0 everywhere) provably contradicts the
bootstrap requirement (Ip < Rt charging current) for normal Rt — derived in the
scratch notes, both constraints reduce to irreconcilable bounds on (k, Rs).
Capacitive regularization needs ~10 nF at the tap (Newton margin), whose ~12 µs time
constant is harmless for ms-scale oscillators but eats the 10 kHz BBD clock the pedal
needs. Fourteen variants were eliminated (VCCS gains, clamps, floors, thyristor/PUT
equivalent — stiff gate unlatches at Ve ≈ Vtap, ripple ~0.1 V; FET/BJT threshold
modulation — offset/threshold flaws; OTA tanh — corrupts the peak gradually;
analog-switch/comparator — no hysteresis; series-R valley — kills the NDR it bounds).

## 3. Minimal stamp addition needed (not implemented — Program/Stamp are off limits)

A node-driven hysteretic switch with memory, evaluated once per sample outside the
Newton loop (the `logic-divider` pattern: commit state before the first Newton pass,
hold across it):

```
{ kind: "hysteretic-switch", a, b, control, thresholdHighVolts, thresholdLowVolts,
  onOhms, offOhms, stateIndex }
```

closes a→b when V(control) rises past high, opens when it falls past low; one state
bit per stamp. With it the UJT lowers to bar + diode (converged statics, already
proven) + hysteretic-switch emitter→B1 (control = emitter, Vhi = eta·Vbb+Vd from the
compile-time rail/divider estimate, Vlo = valley ~1–2 V). No Newton involvement in
the snap by construction. It generalizes beyond UJT (relays, neon lamps, spark gaps,
Schmitt triggers) and is one stamp, one state slot, no new solver capability. The
committed `ujt` DeviceLaw kind, registry contract, builder and override vocabulary
are the lowering's other half and are ready for it.
