# Stompbox Package Plan

## Summary

Create `packages/stompbox` as a headless companion package for converting
`.vdsp` documents into stompbox mechanical outputs.

The boundary is:

- `@vessel-dsp/core` parses, serializes, validates, and preserves `.vdsp`
  schema data.
- `@vessel-dsp/stompbox` interprets core `CircuitDocument` panel data,
  auto-generates missing physical placement, and emits drill-layout data plus
  renderable SVG/GLB preview artifacts.
- UI stays downstream. The package can generate headless artifact data such as
  SVG strings and assembled GLB bytes, but must not add React, canvas editor,
  simulator, Three.js, or browser UI packages.

## Key Changes

- Add package `packages/stompbox` with public exports for drill layouts, drill
  template SVG output, assembled stompbox preview GLB output, 2D preview SVG
  output, asset resolution, and typed CAD part/enclosure catalogs.
- Use `@vessel-dsp/core` public parsing/types only.
- Reuse existing `.vdsp` `panel.faces[].elements[].physical` when present.
- Auto-generate placement when physical placement is absent.
- Auto-generate omitted stompbox hardware when a schematic only describes the
  controls or circuit: status LED, bypass footswitch, input jack, output jack,
  and 9V connector. The 9V connector is generated by default and can be
  explicitly disabled with `includePowerJack: false`.
- Mark every placement with provenance: `vdsp-declared` or `auto-generated`.
- Bundle the CAD part GLBs and STEP companions under
  `packages/stompbox/assets/cad/parts` for default local preview assembly,
  while still allowing callers to override filesystem `basePath` or served
  `baseUrl`.

## Public Outputs

- Drill layout manifest: hole centers, drill diameters, face, labels, bound
  IDs, part profile IDs, asset references, provenance, and diagnostics.
- Drill template SVG:
  - `preview` mode outputs a lightweight SVG for UI preview.
  - `print` mode outputs an A4 1:1 SVG with scale marks and no visible labels
    or hole table.
- Stompbox preview GLB:
  - Assemble the enclosure GLB and v1 part GLBs into one mesh-backed stompbox
    preview GLB with a binary chunk.
  - Apply declared or auto-generated placement transforms, knob rotation, LED
    material state, and footswitch travel before export.
  - Read source GLBs from the bundled asset root by default, or from a caller
    filesystem `basePath`, while preserving resolved asset references in the
    manifest.
- Stompbox preview SVG:
  - Output 2D SVG views for `top`, `bottom`, `left`, and `right`.
  - These views are orthographic preview artifacts for UI display, separate from
    the A4 print drill-template SVG.

## Assumptions

- Default enclosure for v1 is 1590B unless options specify another supported
  enclosure.
- A future Editor writes user-chosen placements back into existing `.vdsp`
  `panel.faces[].elements[].physical`.
- The deleted tracked docs image shown before this work is unrelated and should
  not be restored or modified as part of the package implementation.
