VesselDSP is a TypeScript workspace for headless audio-circuit tooling.

The published packages are:

| Package | Use it for |
| --- | --- |
| `@vessel-dsp/core` | Parse, validate, inspect, and convert circuit documents through `CircuitDocument`, `.vdsp`, LTspice `.asc`, LiveSPICE `.schx`, legacy SPICE netlists, and tscircuit Circuit JSON. |
| `@vessel-dsp/stompbox` | Turn parsed `.vdsp` or `CircuitDocument` panel data into drill layouts, print templates, preview SVG views, and preview GLB artifacts. |

Both packages are headless. They do not ship a browser editor, realtime simulator, React component library, or custom rendering surface. Use downstream tscircuit applications to render or edit emitted Circuit JSON.

## Core data flow

```text
.vdsp / .asc / .schx / .cir / .net / .circuit.json
  -> source-specific parser
  -> CircuitDocument
  -> Circuit JSON / .vdsp / .asc / .schx / legacy netlist output
```

`CircuitDocument` is the normalized in-memory model used for conversion. Source fidelity comes first: unsupported, synthesized, or lossy data should be reported through diagnostics instead of silently converted into schematic semantics.

## Stompbox data flow

```text
.vdsp / CircuitDocument
  -> core parse and validation
  -> declared or generated physical placement
  -> drill layout / A4 print SVG / preview SVG / preview GLB
```

When `.vdsp` panel placement exists, stompbox preserves it. When common enclosure hardware is missing, stompbox owns deterministic mechanical defaults for knobs, jacks, footswitches, status LEDs, and the optional 9V connector.
